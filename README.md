# Patatras Circus (démo)

Jeu de gestion de cirque en vue isométrique, dans l'esprit de Theme Hospital et Theme Park.
Monte ton chapiteau, engage tes artistes, gère la buvette, la sécurité incendie et la réputation pendant une tournée de 16 jours.

**Jouer :** https://den-rode.github.io/game-patatras-circus/

- Navigateur, ordinateur ou téléphone (en paysage)
- Français et anglais
- Sauvegarde locale dans le navigateur, aucun compte, aucune donnée collectée

Version de démo en cours de développement. Les retours sont les bienvenus.
